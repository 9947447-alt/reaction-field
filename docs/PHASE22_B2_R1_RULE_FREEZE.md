## 1. 定位：B2-R1 与 MVP0-P10、Phase 21 的关系

### 1.1 规则版本升级

- **MVP0-P10：** 68 张普通实体卡池；无单质金属卡；无自由离子盐构建表；主动 DIY 每实验周期每名玩家 1 次；响应 DIY 关闭；氧化还原与金属置换不在可玩集合内（见 `docs/MVP0_RULE_FREEZE.md` 暂缓条款）。
- **B2-R1（目标）：** 在保留 MVP0-P10 核心流程（实验周期 / 轮次、关联出牌 `tableReference`、伤害与响应窗口、状态处理）的前提下，引入 **B2-R1 普通实体主牌堆**（离子牌、盐牌、单质金属牌、浓/稀酸碱与点名氧化物/试剂牌等），并以 **离子配平盐生成** 与 **氧化还原白名单表** 作为 DIY 与场面反应的两大合法性来源。

规则版本字符串在 B2-R1 引擎落地后由发布元数据切换为 `B2-R1`；**本文 Frozen v0.1 不触发该切换，也不改写 `package.json`。**

### 1.2 与 Phase 21 的边界

- **Phase 21** 冻结的是 `/play` 呈现引擎（Canvas 2D 牌桌、DOM 壳层、体积门禁），**不改** MVP0-P10 规则与 68 张卡池（见 `docs/PHASE21_PRESENTATION_ENGINE_FREEZE.md`）。
- **Phase 22 / B2-R1** 冻结的是 **下一版化学规则与卡池合同**；可与 Phase 21 呈现层并行规划，但 **B2-R1 规则合入不得被 Phase 21 隐含授权**，须以本文（或其后 Frozen 修订）为准。
- **NATBA-2** 不在 B2-R1 范围；AI 仍按既有 NATBA-1 与 Engine Authority 消费 `GameState`，不读取本文未落地的表。

### 1.3 判定优先级（继承离子手册 §1.1，B2-R1 适用）

1. 牌面【高危】【专业处置】【浓溶液】等专属文字与状态说明。
2. 角色技能、方程式牌（若未来引入）专属文字。
3. **离子对反应**（沉淀 / 气体 / 中和 / 水）— 含 Phase 10 已冻结三类成功反应。
4. **氧化还原表**（§3）— 仅表内行成立。
5. **盐生成 / DIY 配平**（§2.3、§4）— 无直接离子反应且无表内氧化还原时，才走盐构建或浓/稀酸碱 DIY。

“可反应”仍须满足当前时点（主行动、响应、状态处理等）与关联出牌规则；化学表只回答 **物质关系是否成立**。

### 2.3 盐生成规则（DIY 与“可电离”盐牌）

**合同：** 玩家在合法 DIY 时点弃置手牌中对应 **离子组件牌**（元素离子牌或可电离盐牌按牌面拆解为离子，由数据层声明，本文只定规则），当且仅当组合在 **下表配平关系** 内成立时，**构建并打出一张盐物质卡**（进入结算，不入手牌），视为一次正常出牌/DIY 结算。

**配平原则：**

- 阳离子总正电荷 = 阴离子总负电荷（以表中化学计量数为合同，不要求玩家现场演算）。
- 生成物为 **实体盐卡**（B2-R1 卡池内 `substance_*`）；**即使** 对应离子对在沉淀表（§2.4）中标记为难溶，**盐卡仍生成**；沉淀带来的封存 / 抵消 / 状态窗口 **可后置实现**，不得否定盐卡生成事实。
- **Ag₂SO₄** 为明确纳入的可构建盐（硫酸银微溶，仍生成盐卡）：`2Ag⁺ + SO₄²⁻ ⇒ Ag₂SO₄`。
- NO₃⁻ 参与构建的硝酸盐均为可溶性盐构建，不额外触发沉淀反应。

### 2.4 离子对沉淀与气体（与 MVP0 / Phase 10 衔接）

离子对 **公共速查** 与 `ion-reaction-and-diy-manual-v1.0.docx` §三、§四 对齐；B2-R1 至少包含：

- H⁺ + OH⁻ → H₂O（中和，Phase 10 `acid_base_neutralization`）

## 3. 氧化还原反应表（B2-R1 白名单）

### 3.1 合同

- 仅当下表 **行 ID** 被满足（反应物卡种、介质、可选【点燃】【加热】【催化】条件牌）时，氧化还原成立。
- 未列出的组合 **不因** 现实化学常识或玩家自行配平而成立。
- 表规模与离子手册 **第五、六章** 同级：下列分表合计 **多于 40 行** 可执行合同（含条件变体行）。
- 产物中的 **新气体 Cl₂、NO（及浓硝酸路径的 NO₂）** 必须在行内指定 **持续状态施加**（§3.11），**不得** 以即时伤害作为并列结算轨；不得留空。

### 3.2 金属在非氧化性酸（稀酸，H⁺ 来源为稀酸牌或表内介质）

| --- | --- | --- |
| OR-Mg-H | Mg + 2H⁺ → Mg²⁺ + H₂↑ | H₂：可燃气体标签（v0.1 首包）；H₂ 即时伤害数值 **后置、不进首包**（见附录 A） |

## 4. DIY 与响应 DIY（B2-R1 变更）

### 4.1 取消的限制（相对 MVP0-P10）

| MVP0-P10 | B2-R1 |
| --- | --- |

| **响应 DIY 关闭** | **响应 DIY 开放** |

### 4.2 合法性（不变更的化学边界）

主动 DIY 与响应 DIY 均须满足 **之一**：

1. §2.3 盐构建或浓/稀酸碱 DIY 配平表内一行；
2. §2 离子对反应（中和、气体、吸收）在对应窗口可执行；
3. §3 氧化还原表内一行，且条件牌齐全。

**仍禁止：** 表外自创化学式、有机合成、电解定量、原电池电动势计算、砹（At）及相关同位素特例、未在卡池出现的浓硫酸/浓硝酸 **DIY 构建**（浓酸仅预印牌或 §3 产物）。

响应 DIY 继承离子手册精神：构建物须 **立即用于当前响应**，且不得为【高危】标签物质；**是否强制【中和】【吸收】【沉淀】标签** 与 Phase 18 动态 DIY 交集 **后置、不进首包**（见附录 A）。

### 4.3 与 Phase 10、火情、虚拟 DIY 的衔接

- MVP0 遗留的 **虚拟 DIY**（CO₂/H₂O 灭火、SO₂ 泄漏、虚拟酸碱攻击）在 B2-R1 中 **保留**，直至独立文档废止。
- **三类成功反应事件**（§6）不因 DIY 次数解禁而扩展定义 ID。
- DIY **不** 绕过浓/稀卡面属性；浓盐酸参与 §3.8 行时须为 **浓 HCl** 牌。
